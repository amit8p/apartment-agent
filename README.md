# 🏠 סוכן חיפוש דירות

סורק את יד2 כל ~5 דקות, 24/7, ושולח לטלגרם כל דירה חדשה שמתאימה לך (עם תמונה, מחיר, חדרים, כתובת ולינק), וגם התראה כשדירה מורידה מחיר. רץ בחינם על GitHub, גם כשהמחשב כבוי.

ההתקנה לוקחת בערך 15 דקות, פעם אחת.

---

## שלב 1: בוט בטלגרם (3 דקות)

1. בטלגרם, חפשי את **@BotFather** ושלחי לו `/newbot`
   (הבוט הנכון: שם המשתמש בדיוק `@BotFather` ו-✔️ כחול ליד השם. אם מבקשים ממך כסף או סיסמה - זה מזויף)
2. תני שם לבוט (למשל "דירות של אוהד") ושם משתמש שנגמר ב-bot (למשל `ohad_dirot_bot`)
3. הוא ישלח לך **טוקן** שנראה ככה: `7412345678:AAH...` - שמרי אותו
4. פתחי את הבוט החדש שלך ושלחי לו הודעה כלשהי (למשל "היי")
5. עכשיו צריך את ה-**Chat ID** שלך (מספר שאומר לבוט למי לשלוח). הדרך הכי קלה:
   בטלגרם חפשי את **@userinfobot**, לחצי **Start** - הוא יענה מיד עם השורה `Id: 123456789`
6. המספר הזה הוא ה-Chat ID שלך - שמרי אותו (רק הספרות)

   <details><summary>דרך חלופית, אם @userinfobot לא עובד</summary>

   הדביקי בשורת הכתובת בדפדפן `https://api.telegram.org/bot` ומיד אחריו, בלי רווח, את הטוקן, ואז `/getUpdates`. לדוגמה:
   `https://api.telegram.org/bot7412345678:AAHabc123/getUpdates`
   בעמוד שייפתח חפשי `"chat":{"id":` - המספר שאחריו הוא ה-Chat ID.
   אם מופיע רק `"result":[]` - שלחי עוד הודעה לבוט שלך ורענני את העמוד.
   </details>

## שלב 2: לינק החיפוש מיד2 (2 דקות)

1. היכנסי ל-yad2.co.il > נדל"ן > השכרה
2. סמני עיר / שכונות, טווח מחיר, מספר חדרים וכל סינון אחר
3. מייני לפי **"תאריך - מהחדש לישן"**
4. העתיקי את הכתובת המלאה משורת הכתובת של הדפדפן

## שלב 3: ריפו ב-GitHub (7 דקות)

1. צרי חשבון ב-github.com (אם אין)
2. לחצי **+** למעלה > **New repository**
   - שם: `apartment-agent`
   - בחרי **Public** (ככה זה בחינם בלי הגבלת דקות. הסודות - הטוקן וה-Chat ID - נשארים מוסתרים)
   - לחצי **Create repository**
3. לחצי **uploading an existing file** וגררי את הקבצים: `agent.py`, `config.yaml`, `requirements.txt`, `README.md` > **Commit changes**
4. את קובץ התזמון יוצרים ידנית (תיקיות שמתחילות בנקודה לא תמיד נגררות):
   **Add file > Create new file**, בשם הקובץ הקלידי בדיוק:
   `.github/workflows/apartment-agent.yml`
   והדביקי את התוכן של הקובץ `apartment-agent.yml` > **Commit changes**

## שלב 4: סודות והגדרות (3 דקות)

1. בריפו: **Settings > Secrets and variables > Actions > New repository secret**
   - שם `TELEGRAM_BOT_TOKEN`, ערך: הטוקן משלב 1
   - שם `TELEGRAM_CHAT_ID`, ערך: ה-Chat ID משלב 1
2. פתחי את `config.yaml` בריפו, לחצי על העיפרון ✏️:
   - הקריטריונים שלך כבר מוגדרים (תל אביב, עד 7,500 ₪, 2+ חדרים, חניה/תו, מוארת, בלי נווה שאנן, עדיפות למרכז)
   - מומלץ להחליף את הלינק תחת `yad2_searches` בלינק חיפוש משלך שממוין "מהחדש לישן" (שלב 2)
   - **Commit changes**

## שלב 5: הפעלה

1. לשונית **Actions** > אם מופיעה הודעה, לחצי **I understand... enable them**
2. בחרי **apartment-agent** > **Run workflow**
3. תוך דקה תקבלי בטלגרם: "🟢 סוכן הדירות פעיל!"

מעכשיו הוא רץ לבד. בריצה הראשונה הוא רק "לומד" את המודעות הקיימות, ומהריצה הבאה שולח רק חדשות.

## שינוי קריטריונים

עורכים את `config.yaml` ישירות ב-GitHub (עיפרון ✏️). השינוי נכנס לתוקף מהריצה הבאה.

| הגדרה | מה זה עושה |
|---|---|
| `yad2_searches` | לינקים לחיפושים ביד2. אפשר כמה, למשל שכונה בכל אחד |
| `max_price` / `min_rooms` וכו' | סינון נוסף על מה שיד2 מחזיר |
| `exclude_agency: true` | רק מודעות פרטיות |
| `neighborhoods` | רק שכונות מסוימות |
| `must_include_any` | חייב להופיע לפחות אחד: "מרפסת", "חניה", "ממ"ד" |
| `exclude_keywords` | לדלג על מודעות עם המילים האלה |
| `alert_price_drops` | התראה על ירידת מחיר |

## עצירה זמנית

**Actions > apartment-agent > ⋯ > Disable workflow**. להפעלה מחדש: Enable.

## דברים שכדאי לדעת

- **GitHub לפעמים מאחר** בריצות המתוזמנות (5 דקות יכולות להיות 10-15 בשעות עומס).
- **יד2 חוסם לפעמים** סריקות אוטומטיות. הסוכן מנסה קודם בקשה רגילה ואז דפדפן אמיתי. אם שניהם נחסמים תקבלי התראה (לכל היותר פעם ב-6 שעות), ובדרך כלל זה מסתדר לבד.
- **ריפו שלא היה בו שום שינוי 60 יום** - GitHub מכבה את התזמון. הסוכן שומר את המודעות שראה בריפו, כך שכל עוד עולות דירות חדשות זה לא יקרה.
